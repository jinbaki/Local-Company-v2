## 초기 구현 추천 순서

처음에는 다음 5개만 구현한다.

1. 캠페인 생성
2. PM 대화
3. PM 액션으로 목표/태스크/산출물 생성
4. 산출물 저장소
5. 작업 큐로 직원 1명 실행

이 5개가 잘 되면 나머지는 자연스럽게 붙일 수 있다.
